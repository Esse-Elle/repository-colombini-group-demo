# Repository Colombini Group, demo

Prototipo del repository asset del Gruppo Colombini: home di gruppo e sezione Febal Casa.

Contenuti di prova: illustrazioni, documenti e cataloghi a tema gattini, creati per il test. Nessun materiale reale di prodotto.

## Cosa si prova
- Anteprima di foto, PDF, loghi e font prima del download
- Download di un file, di una selezione o di tutta la cartella in ZIP
- Foto catalogo archiviate solo in alta: la versione social HD a 150 dpi si crea al momento del download
- Accesso tramite link per profilo (marketing di gruppo, dipendente, agente Febal Casa)

## Struttura
- `index.html`: la pagina
- `fc/`: file scaricabili di Febal Casa (brand, catalogo, ped, pdf)
- `thumbs/`, `pages/`: anteprime
- `group/`: grafica e loghi di gruppo
